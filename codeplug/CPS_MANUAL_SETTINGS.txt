D578UV CPS MANUAL CONFIGURATION
================================
Use I2Base.db3 as the CPS project file. It contains:
- All 38 channels (HIGH power)
- All 6 Radio IDs pre-configured
- MAIN zone with all channels

Only these settings need manual configuration in CPS:

=====================================
1. RADIO ID LIST (ALREADY CONFIGURED)
=====================================
I2Base.db3 already has all 6 Radio IDs configured:
- ID 1: I2Base (DMR ID 100) - AT-D578UV base station
- ID 2: I2 (DMR ID 101) - DRN HT
- ID 3: MrSI2 (DMR ID 102) - DJN HT
- ID 4: LiLI21 (DMR ID 1) - EJD HT
- ID 5: LiLI22 (DMR ID 2) - JGN HT
- ID 6: LiLI23 (DMR ID 3) - MAN HT

Verify at: Optional Setting > Radio ID List

=====================================

Then assign to channels:
- ENCRYPTED 1 > Digital Encryption = KEY1
- ENCRYPTED 2 > Digital Encryption = KEY2
- ENCRYPTED 3 > Digital Encryption = KEY3

=====================================
3. P-KEY ASSIGNMENTS
=====================================
Optional Setting > Key Function

SHORT PRESS:
- P1 Short: Scan On/Off
- P2 Short: A/B
- P3 Short: Repeater
- P4 Short: Record
- P5 Short: Sub PTT
- P6 Short: Encryption On/Off

LONG PRESS:
- P1 Long: Scan List
- P2 Long: Main Channel
- P3 Long: Talk Around
- P4 Long: Record List
- P5 Long: Squelch Off
- P6 Long: Voltage

=====================================
4. REPEATER MODE SETTINGS
=====================================
Optional Setting > Other > Rep-Mode Setting

For Single Frequency DMR Repeater (timeslot interleave):
- Rep-Mode: On
- DMR Mode: Double Slot (DCDM TS Split)
- Cross Band: Off (for same-band repeat)
- Slot: Time Slot 1 (base RX)

On HTs connecting to this repeater:
- Talkaround: OFF (critical!)
- DMR Mode: DCDM TS Split
- Or: One HT on TS1, other on TS2

=====================================
5. SCAN SETTINGS
=====================================
Optional Setting > Scan

- Scan Mode: Time Operated (TO)
- Priority Channel: On
- Dwell Time: 0.3s (fast)
- Dropout Delay: 0.3s (fast)
- Look Back Time A: 1.5s
- Look Back Time B: 1.5s

=====================================
6. POWER SETTINGS (BASE STATION)
=====================================
All channels already set to HIGH power.

Optional Setting > Power On
- Set startup zone to ENCRYPTED
- Set startup channel to ENCRYPTED 1

=====================================
HOW TO USE I2Base.db3:
=====================================
1. File > Open > I2Base.db3
2. Manual: Add Encryption Keys (section 2)
3. Manual: Assign keys to channels ENCRYPTED 1-3
4. Manual: P-Key assignments (section 3)
5. Manual: Repeater settings (section 4)
6. Manual: Scan settings (section 5)
7. Program > Write to Radio

Note: Channels, Radio IDs, and zones are already configured.
The CodeplugSample.rdt is a minimal sample for reference only.

D578UV CPS MANUAL CONFIGURATION
================================

CSV IMPORT FILES:
-----------------
- channels.csv     - 38 channels (HIGH power)
- zones.csv        - MAIN zone with all channels
- scanlist.csv     - Main Scan (channels 1,2,3,5)
- radioid.csv      - 6 Radio IDs
- talkgroups.csv   - Contacts/Talk Groups
- encryption.csv   - AES-256 encryption keys

IMPORT INSTRUCTIONS:
--------------------
1. Tools > Mode > Check "Channel name is not unique"
2. Tool > Import
3. Click "Import From File List" and select I2Base.lst
   (OR import each CSV individually using buttons on left)

IMPORT ORDER (if importing individually):
1. Radio ID List (radioid.csv)
2. Talk Groups (talkgroups.csv)
3. Channels (channels.csv)
4. Zones (zones.csv)
5. Scan List (scanlist.csv)

After import, these settings need manual configuration:

=====================================
3. P-KEY ASSIGNMENTS
=====================================
Optional Setting > Key Function

SHORT PRESS:
- P1 Short: Scan On/Off
- P2 Short: A/B
- P3 Short: Repeater
- P4 Short: Record
- P5 Short: Sub PTT
- P6 Short: Encryption On/Off

LONG PRESS:
- P1 Long: Scan List
- P2 Long: Main Channel
- P3 Long: Talk Around
- P4 Long: Record List
- P5 Long: Squelch Off
- P6 Long: Voltage

=====================================
4. REPEATER MODE SETTINGS
=====================================
Optional Setting > Other > Rep-Mode Setting

For Single Frequency DMR Repeater (timeslot interleave):
- Rep-Mode: On
- DMR Mode: Double Slot (DCDM TS Split)
- Cross Band: Off (for same-band repeat)
- Slot: Time Slot 1 (base RX)

On HTs connecting to this repeater:
- Talkaround: OFF (critical!)
- DMR Mode: DCDM TS Split
- Or: One HT on TS1, other on TS2

DM-32UV HANDHELD CONFIGURATION FOR SFR:
---------------------------------------
The DM-32UV supports DCDM (Dual Capacity Direct Mode) for
dual timeslot simplex operation. On the radio menu:

1. Set channel to same frequency as AT-D578UV base
2. Set correct timeslot (TS1 or TS2)
3. Match color code to base station
4. "Dual Mode" setting (if visible on radio):
   - This enables DCDM dual timeslot operation
   - Allows proper SFR communication
   - When enabled, timeslot settings are enforced
5. Talkaround/Simplex: MUST be OFF

Note: "Dual Mode" on DM-32UV can mean:
- Analog/Digital dual mode (FM vs DMR switching)
- DCDM/Dual Slot mode (timeslot operation)
Check channel settings for DCDM-related options.

=====================================
5. SCAN SETTINGS
=====================================
Optional Setting > Scan

- Scan Mode: Time Operated (TO)
- Priority Channel: On
- Dwell Time: 0.3s (fast)
- Dropout Delay: 0.3s (fast)
- Look Back Time A: 1.5s
- Look Back Time B: 1.5s

=====================================
6. POWER SETTINGS (BASE STATION)
=====================================
All channels already set to HIGH power.

Optional Setting > Power On
- Set startup zone to ENCRYPTED
- Set startup channel to ENCRYPTED 1

=====================================
COMPLETE SETUP PROCEDURE:
=====================================
1. Tools > Mode > Check "Channel name is not unique"
2. Tool > Import > Import each CSV (or use I2Base.lst)
3. Manual: Add Encryption Keys (section 2)
4. Manual: Assign keys to channels ENCRYPTED 1-3
5. Manual: P-Key assignments (section 3)
6. Manual: Repeater settings (section 4)
7. Manual: Scan settings (section 5)
8. Program > Write to Radio
